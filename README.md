# AI Career Recommendation System

An AI-powered career recommendation system built using Python, Streamlit, and Machine Learning.

## Features
- Career Recommendations
- Skill Gap Analysis
- Career Roadmap
- Match Percentage
- Interactive Streamlit Interface

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-Learn
- NLP (TF-IDF)

## How to Run

pip install -r requirements.txt

streamlit run app.py
